# pitch_gravity_compensation
一个控制二维云台pitch轴控制补偿的方法
首先这个重力补偿的方法有很多地方上仅限于达妙的电机可以做到
对于这个文件里面的内容需要注意的是，每个分支内容的使用顺序以及它的具体作用
注意：达妙电机一定要先标定零点
  1.需要使用damiao_position_KPKD_get分支配置kp和kd，从而使电机能到达你设定的目标位置，实际上，在文件里面使用的是达妙电机的位置速度模式，调参实现的效果不会太精确，但是，对于采样重力补偿的角度和力矩对应关系的情景下，位置速度模式刚刚好，其中，kp和kd的参数甚至只需要p项合格就行，这样你的参数就可以使用了，当然如果是RM实际应用上肯定是不够用的
  2.使用damiao_angle_torque_get文件，这个文件具体就是在你设定的最大最小角度下，以每5度增加或减少来遍历你给定的次数，并在每个角度稳定的情况下通过串口发送给vofa+,在发送完成的基础上，需要将发送好的数据复制到txt文本里面，然后改成angle-torque.csv文件
  3.将可以使用的angle-torque.csv文件放到parameter_get.m一样的文件夹里面然后可以通过matlab文件得到需要的参数
  4.将matlab输出的参数放到最终的测试代码damiao_gravity_compensate里面，就能直接测试这个重力补偿的适应性如何
